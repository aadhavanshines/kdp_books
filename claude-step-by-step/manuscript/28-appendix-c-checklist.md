# Appendix C: One-Page Setup Checklist

Work down this list once, and Claude will be set up the way that suits you.

## Account and Apps

| Done | Step | Chapter |
| --- | --- | --- |
| | Sign up at claude.ai with the sign-in you'll use everywhere | 2 |
| | Install the desktop app on your computer | 2 |
| | Install the mobile app on your phone | 2 |
| | Choose a plan; start on Free unless you need more | 2 |

## Settings

| Done | Step | Chapter |
| --- | --- | --- |
| | Write your "about me" instructions in your profile | 2 |
| | Choose your appearance (light or dark) | 2 |
| | Check Settings > Privacy and choose whether your chats help train models | 23 |
| | Check Settings > Memory: on or off, sensitive topics, and your topics list | 10 |
| | Connect one app you use every day (calendar or email) | 12 |
| | Decide on Manual or Auto, and set "Always ask" for sending and deleting | 12 |
