# Appendix A: Request Library

Copy, fill in the brackets, and send. Every request follows the Finished-Work Formula from Chapter 4.

## Writing

| Need | Request |
| --- | --- |
| Reply to an email | Reply to this email from [who]. I want to [goal]. Tone: [tone]. Under [N] words. [paste email] |
| Shorten | Cut this to [N] words without losing any facts or dates. |
| Change tone | Rewrite this to sound [warmer / more formal / more confident], keeping every fact. |
| Proofread, keep my voice | List every mistake in a table (original, fix, reason). Don't rewrite the rest. |
| Options | Give me [N] versions, from most formal to most casual. Mark the one you'd pick. |
| Personal note | Write a [card / note] to [who] about [occasion]. One real detail: [memory]. [N] sentences. |

## Reading

| Need | Request |
| --- | --- |
| Brief | Summarize this for [reader] who has [time]. Bottom line first, then [N] key points with page numbers, then actions. |
| Decode | In plain English: what is this saying, do I owe or need to do anything, is there a deadline, what should I do next? |
| Skeptic | Read this as a careful skeptic. What's missing, unclear, inconsistent or risky? |
| Compare | Compare these [files] in a table: [columns]. Then which fits [my need] best, and what to ask each. |
| Catch up | What's been decided, what's open, who's waiting on whom, and is anything waiting on me? |

## Thinking and Deciding

| Need | Request |
| --- | --- |
| Ask me first | Before you write anything, ask me the questions you need answered. Ask them all at once. |
| Pros and cons | I'm deciding between [A] and [B]. My priorities: [list]. Compare them in a table and tell me what I might be missing. |
| Honest critique | Be a tough [expert]. Give me the five biggest weaknesses, most serious first. |
| Practice | Play [person] in [situation]. Be realistic. After each of my replies, give me one tip. |
| Check yourself | Check your answer against my original request and list anything you missed. Which facts are you least sure of? |

## Making Things

| Need | Request |
| --- | --- |
| Document | Write a [type] for [reader] as a Word document: [sections]. [Tone]. |
| Spreadsheet | Make an Excel file with columns [list], my numbers [data], totals as formulas, and [highlight rule]. |
| Deck | Make a [N]-slide deck for a [length] talk to [audience] about [topic]. One idea per slide, speaker notes. |
| Tool | Build a [tool] where I [type/tap what] and see [what]. [Look and feel]. Remember my data between visits. |
| Chart | Turn this data into an interactive chart where I can [filter/compare]. |

## Learning

| Need | Request |
| --- | --- |
| Tutor | You're my [subject] tutor; I'm in [grade]. Don't give answers; ask one question at a time. |
| Three levels | Explain [topic] three ways: for a 10-year-old, a high-school student and a [professional]. |
| Crash course | Give me a one-hour crash course on [topic]: 10 key terms, how it works, common worries, 5 smart questions. |
| Quiz | Quiz me on [topic], one question at a time, and tell me why when I'm wrong. |
