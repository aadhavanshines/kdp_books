# Chapter 24: Troubleshooting and Making Your Allowance Last

Things occasionally go wrong: you hit a usage limit, a file won't upload, an answer stops halfway, a button isn't where the book says it is. This chapter gives you the quick fix for each.

## If Your Screen Looks Different

Claude's design changes several times a year. If a button in this book isn't where you expect:

1. **Look for the same word.** Features keep their names much longer than their positions. "Projects," "Artifacts," "Scheduled" and "Memory" are the words to look for.
2. **Check the + menu.** New options for a single chat usually appear there first.
3. **Check Settings and Customize.** Account-wide options (memory, connectors, skills, privacy) live in Settings or the Customize area.
4. **Use Search.** Press Ctrl+K (Cmd+K) and type the feature's name; it often finds settings as well as chats.
5. **Ask Claude.** "Where do I turn on Research in the Claude app?" Claude can usually tell you, especially with web search, and the official help center at support.claude.com has step-by-step articles for every feature.

> **Tip:** On the phone, most options are behind the menu button (three lines) at the top, or the + button next to the message box.

## Usage Limits

Every plan has a limit on how much you can use Claude in a few hours and in a week. When you get close, you'll see a message such as **"Over 90% of your 5-hour limit used,"** along with the time it resets.

### Making your allowance last

| Habit | Why it helps |
| --- | --- |
| Start a new chat for each new task | Long chats re-read everything earlier in the conversation with every message |
| Use Projects for big files | Files are handled more efficiently than re-uploading them into every chat |
| Choose a lighter model for simple jobs | Sonnet and Haiku use less of your allowance than Opus or Fable |
| Lower the effort for easy questions | Less thinking time, less usage |
| Ask for everything in one message | One clear request beats five small corrections |
| Ask for shorter answers | "In under 100 words" when you don't need more |

### When you hit the limit

- Wait for the reset time shown in the message.
- Switch to a lighter model if your plan allows.
- Upgrade, or buy extra usage, if you hit the limit regularly.

## Common Problems and Fixes

| Problem | Try this |
| --- | --- |
| The answer stopped halfway | Type "continue" |
| A file won't upload | Check the file size; save a scanned PDF as a smaller file; or upload it in parts |
| Claude misread a photo | Retake it in better light, straight on; or tell Claude which part is wrong |
| Answers are generic | Add raw material: the facts, the document, an example (Chapter 4) |
| Claude forgot something from earlier | The chat may be very long. Start a new chat with a short summary, or use a Project |
| Claude keeps using a style I don't like | Put the rule in your profile instructions, so it applies everywhere |
| A connector isn't working | Disconnect and reconnect it in Settings; check you're signed in to the right account |
| An artifact has a bug | Describe what you tapped, what happened and what you expected (Chapter 21) |
| Claude refuses a reasonable request | Add context about who you are and why you're asking (Chapter 5) |
| The app is slow or won't load | Refresh the page, update the app, or check status.anthropic.com for outages |

## Getting Help

- **Help center:** support.claude.com has guides for every feature and plan question.
- **Status page:** status.anthropic.com shows whether Claude is having problems right now.
- **In the app:** the help or feedback options in Settings let you contact support or report a bad answer.
- **The thumbs-down button** under any answer tells Anthropic something went wrong. It's worth using.

## Key Points

- If a button moved, look for the same word, check the + menu and Settings, or ask Claude.
- New chats, Projects, lighter models and clear requests make your allowance last.
- "Continue" finishes an answer that stopped.
- For any problem, more context and a fresh chat fix most things.
