# Claude AI Step by Step

*The Visual Beginner's Guide to Getting Finished Work from Claude, with 50 Real Workflows, Step-by-Step Illustrations and No Coding* (AI Skillup series), by Aadhavan Muthurengan.

| Folder | Contents |
| --- | --- |
| `manuscript/` | Chapters in Markdown, plus `images/` (processed screenshots and diagrams) |
| `build/` | `build.py` (EPUB, interior PDF, covers), `screens.py` (screenshot processing and privacy blur), `figures.py` (diagrams), `covers.py` |
| `demo-files/` | Fictional lease, contractor quotes and receipt used in the screenshots |
| `screens-raw/` | Raw captures (deleted after processing for privacy; recapture to rebuild screenshots). Git-ignored |
| `metadata/kdp-listing.md` | Title, description, keywords, categories, prices, AI disclosure |
| `tests/CHECKS.md` | Pre-upload checks and results |
| `dist/` | Upload-ready files |

Build: `python3 build/build.py`
