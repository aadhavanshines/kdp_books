## A Note on the Project Code

Every code listing in this book was printed directly from the tested project files, and every prompt in the project chapters was run in Claude Code. Because Claude's output varies, your own versions of these projects will differ in the details. That's expected: use the book's listings as a reference for what good looks like, not as code you must match exactly.
