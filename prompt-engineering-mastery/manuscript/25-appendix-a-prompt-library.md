# Appendix A: Quick-Reference Prompt Library

This appendix collects 50 ready-to-use prompts. Each one works with any major AI assistant. Replace the parts in angle brackets with your own details, and add context generously: the more specific you are, the better the result.

## Writing

**Prompt 01: First draft.** *Use when you're starting any document from a blank page.*

```
Write a <document type> for <audience> about <topic>. The goal is
to <purpose>. Include <key points>. Tone: <tone>. Length: <length>.
```

**Prompt 02: Edit for clarity.** *Use when your own draft is wordy or unclear.*

```
Edit this for clarity and concision without changing my voice or
meaning. Then list your 5 most important changes.
<paste your text>
```

**Prompt 03: Simplify.** *Use when you need to explain something to a young or non-expert reader.*

```
Rewrite this so a 12-year-old could understand it, keeping all
the key facts: <paste your text>
```

**Prompt 04: Change tone.** *Use when a message sounds too blunt, too stiff, or too casual.*

```
Rewrite this message to sound <tone, e.g., warmer and more
confident> while keeping it under <length>: <paste your text>
```

**Prompt 05: Headlines.** *Use when you need a title that gets clicks.*

```
Give me 10 headlines for this article. Mix curiosity, benefit,
and direct styles. Mark your top 3 and explain why.
<article summary>
```

**Prompt 06: Outline.** *Use when you're planning a long document before writing it.*

```
Create a detailed outline for a <length> <document type> on <topic>
for <audience>, with section headings and 2-3 key points each.
```

**Prompt 07: Expand notes into prose.** *Use when you have bullet notes that need to become readable text.*

```
Turn these bullet notes into well-written paragraphs. Don't add
facts that aren't in the notes. <paste your notes>
```

**Prompt 08: Critique.** *Use when you want honest, specific feedback on a draft.*

```
Act as a demanding editor. Identify the 5 biggest weaknesses in
this draft, in order of importance, with specific fixes. <paste
draft>
```

## Summarizing and Understanding

**Prompt 09: Executive summary.** *Use when a decision-maker needs the essence in seconds.*

```
Summarize this in 3 bullet points for a busy executive deciding
<decision>. <paste document>
```

**Prompt 10: Key takeaways and actions.** *Use when you need the conclusions and actions from a long document.*

```
From this document, list: the main conclusion, 5 key facts, and
any actions or deadlines. Use only information in the text.
<paste document>
```

**Prompt 11: Meeting notes.** *Use when you have a meeting transcript or recording to turn into notes.*

```
Turn this transcript into notes with sections: Decisions, Action
Items (owner, task, due date), and Open Questions. Write "None"
for empty sections. <paste transcript>
```

**Prompt 12: Explain like I'm new.** *Use when you're learning an unfamiliar topic.*

```
Explain <concept> to someone with a background in <field>. Use an
analogy, then an example, then 3 questions to check understanding.
```

**Prompt 13: Compare documents.** *Use when you need to see exactly what changed between two versions.*

```
Compare these two versions. List every substantive change in a
table: Section, Before, After, Significance.
<version 1> <version 2>
```

**Prompt 14: Q&A from a document.** *Use when you need answers grounded in one specific document.*

```
Answer my question using only the document below. Quote the
relevant passage first. If the answer isn't there, say so.
<paste document> Question: <question>
```

## Learning

**Prompt 15: Learning plan.** *Use when you want a structured plan to learn a new skill.*

```
Create a <weeks>-week plan to learn <skill> to the level of
<goal>, with <hours> hours per week, free resources, and weekly
milestones.
```

**Prompt 16: Socratic tutor.** *Use when you want to understand something deeply rather than be told.*

```
Be my Socratic tutor for <topic>. Ask guiding questions instead
of giving answers. Give a hint only after two wrong attempts.
```

**Prompt 17: Quiz me.** *Use when you want to test your own knowledge.*

```
Quiz me on <topic> with 10 questions of increasing difficulty,
one at a time. Explain each answer after I respond.
```

**Prompt 18: Flashcards.** *Use when you're revising for an exam or memorizing key facts.*

```
Create 20 flashcards from this material in a two-column table:
Question | Answer. <paste material>
```

## Analysis and Decisions

**Prompt 19: Decision matrix.** *Use when you're choosing between options with several criteria.*

```
Compare <options> against these criteria: <criteria with weights>.
Show a scored table, then recommend one and list your assumptions.
```

**Prompt 20: Pre-mortem.** *Use when you want to find the weak points of a plan before starting.*

```
Imagine <plan> failed a year from now. List the 7 most likely
reasons, with an early warning sign and a prevention step for each.
```

**Prompt 21: Devil's advocate.** *Use when you want to stress-test an argument or proposal.*

```
Steelman the strongest case against this argument, then tell me
which objection I most need to address. <paste argument>
```

**Prompt 22: SWOT analysis.** *Use when you're assessing a business, product, or idea.*

```
Create a SWOT analysis for <business/idea> in <market>. Be
specific to my situation: <context>.
```

**Prompt 23: Root cause analysis.** *Use when something keeps going wrong and you need the real cause.*

```
Problem: <problem>. Use the "5 Whys" method to explore likely root
causes. Then suggest how to verify the most likely cause.
```

**Prompt 24: Data insights.** *Use when you have numbers and want to know what they mean.*

```
Analyze this data. Describe key trends, anomalies, and 3 possible
explanations. Show calculations. Note what extra data would help.
<paste data>
```

## Communication

**Prompt 25: Difficult email.** *Use when you must write a sensitive or awkward email.*

```
Write an email to <recipient> about <situation>. I need <outcome>.
Tone: <tone>. Give a direct version and a diplomatic version.
```

**Prompt 26: Reply to a complaint.** *Use when a customer is unhappy and you need a calm reply.*

```
Draft a reply to this customer complaint. Acknowledge the issue,
apologize once, explain next steps, and keep it under 150 words.
<paste complaint>
```

**Prompt 27: Meeting prep.** *Use when you're preparing for an important meeting or negotiation.*

```
I'm meeting <person> about <topic> to achieve <goal>. List my 3
key messages, their 5 likely objections with responses, and a
strong opening line.
```

**Prompt 28: Role-play practice.** *Use when you want to rehearse a pitch, interview, or tough conversation.*

```
Role-play as <role> so I can practice <scenario>. Push back
realistically. After 6 exchanges, give me feedback.
```

**Prompt 29: Presentation outline.** *Use when you need a slide deck structure quickly.*

```
Create a 10-slide presentation outline on <topic> for <audience>.
For each slide: title, 3 bullet points, and a speaker note.
```

**Prompt 30: Social post.** *Use when you're announcing news on social media.*

```
Write a <platform> post announcing <news> for <audience>. Hook in
the first line, one concrete detail, clear call to action, under
<length>.
```

## Career and Business

**Prompt 31: Resume bullets.** *Use when you're updating your resume.*

```
Rewrite these resume bullets to start with action verbs and show
measurable results. Ask me for numbers if needed. <paste your
bullets>
```

**Prompt 32: Cover letter.** *Use when you're applying for a specific job.*

```
Write a cover letter for <job title> at <company>.
My experience: <summary>. Their requirements: <requirements>.
Show how my experience matches their top 3 requirements. Under 300
words, confident, not generic.
```

**Prompt 33: Interview prep.** *Use when you have an interview coming up.*

```
List 10 likely interview questions for <role> at <company type>,
with strong answer frameworks based on my background: <summary>.
```

**Prompt 34: Business idea validation.** *Use when you want to test an idea before investing in it.*

```
Evaluate this business idea: <idea>. Cover target customers,
competition, risks, and the 3 cheapest ways to test demand.
```

**Prompt 35: Marketing personas.** *Use when you need to understand who your customers are.*

```
Create 3 customer personas for <product>, each with goals, pain
points, objections, and where they spend time online.
```

**Prompt 36: Product description.** *Use when you're selling a product online.*

```
Write a product description for <product> with features
<features> for <audience>. 50-word paragraph plus 4 benefit
bullets. No hype words.
```

## Planning and Productivity

**Prompt 37: Project plan.** *Use when you're starting a project with a deadline and a team.*

```
Create a project plan for <project> due <date>, team <team>.
Table with phases, tasks, owners, durations, dependencies; then
top 5 risks with mitigations.
```

**Prompt 38: Prioritize tasks.** *Use when you have too many tasks and too little time.*

```
My goal this week is <goal>, with <hours> focused hours. Sort
these tasks into Do Today, This Week, Delegate, Drop, with reasons.
<paste your tasks>
```

**Prompt 39: Break down a big task.** *Use when a task feels too big to start.*

```
Break <large task> into steps that each take under 1 hour. Order
them logically and mark which can be done in parallel.
```

**Prompt 40: Weekly review.** *Use when you want to reflect on the week and plan the next.*

```
Here's what I did this week and my goals: <paste your notes>.
Summarize progress, identify what's slipping, and suggest 3
priorities for next week.
```

## Coding and Technical

**Prompt 41: Explain code.** *Use when you need to understand unfamiliar code.*

```
Explain what this code does, step by step, for a developer new to
the codebase. Flag edge cases and potential bugs. <paste code>
```

**Prompt 42: Debug.** *Use when code fails and you can't see why.*

```
This code fails with the error below. Expected: <expected>.
I've tried: <attempts>. Find the cause and propose a fix.
<paste code> <paste error>
```

**Prompt 43: Write tests.** *Use when you need tests for a function.*

```
Write unit tests for <function> covering normal cases, boundary
values, and invalid inputs, using <framework>. <paste code>
```

**Prompt 44: Code review.** *Use when you want a second opinion on code before merging.*

```
Review this code for correctness, security, and performance
issues, in that order. Explain each issue and suggest a fix.
<paste code>
```

**Prompt 45: Spreadsheet formula.** *Use when you need a spreadsheet formula but don't know the syntax.*

```
In <Excel/Google Sheets>, column A has <what column A holds>,
column B has <what column B holds>. Write a formula that <goal>,
and explain how it works.
```

## Prompts About Prompts

**Prompt 46: Improve my prompt.** *Use when a prompt isn't giving you the results you want.*

```
Review this prompt for ambiguity, missing context, and conflicting
instructions. Then rewrite it to be clearer. <paste prompt>
```

**Prompt 47: Interview me first.** *Use when you're not sure what information the AI needs from you.*

```
I want help with <task>. Before starting, ask me up to 8 questions
about anything you need to do it well.
```

**Prompt 48: Generate a system prompt.** *Use when you're creating a custom assistant or AI feature.*

```
Write a system prompt for an AI assistant that <purpose> for
<users>. Include identity, audience, knowledge sources, response
style, boundaries, and two example exchanges.
```

**Prompt 49: Create test cases.** *Use when you need to test a prompt before relying on it.*

```
Generate 20 diverse test inputs for this prompt, including edge
cases and tricky cases, with a note on what a good output must
do for each. <paste prompt>
```

**Prompt 50: Diagnose a failure.** *Use when an output missed the mark and you want to know why.*

```
I gave you this prompt <paste prompt> and got this output <paste
output>, but I wanted <desired result>. Explain what in the
prompt caused the gap, and rewrite the prompt to fix it.
```
