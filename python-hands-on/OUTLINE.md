# Python Programming Hands-On: Outline

**Title:** Python Programming Hands-On
**Subtitle:** Learn Python from Basic to Advanced by Writing Real Programs, with Exercises, Solutions and Every Example Tested
**Audience:** complete beginners to intermediate programmers; no programming experience needed.
**Promise:** every listing in the book is a real file that was run on Python 3.12, 3.13, 3.14 and 3.15; the output printed is the output it produced.
**Running project:** Pocket Library, a personal book collection and reading tracker that grows from a list (Chapter 6) to a tested, packaged command-line app with SQLite (Chapter 23) and a small web API (Chapter 25).
