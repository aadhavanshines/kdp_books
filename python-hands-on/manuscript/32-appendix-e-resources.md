# Appendix E: Resources

These official sources were checked in October 2026. Web addresses change, so if one doesn't work, search for the project's name.

## Python

- **Python downloads:** python.org/downloads. Installers for Windows (the Python install manager), macOS and other systems.
- **Python documentation:** docs.python.org. The official tutorial, the library reference for every standard module, and "What's New" for each version.
- **Python Enhancement Proposals:** peps.python.org. The design documents behind new features, such as PEP 8, the style guide for Python code.
- **Python Packaging User Guide:** packaging.python.org. Virtual environments, `pyproject.toml`, building wheels and publishing to PyPI.
- **The Python Package Index:** pypi.org.
- **Python discussion forum:** discuss.python.org.

## Tools Used in This Book

- **pytest:** docs.pytest.org.
- **mypy:** mypy.readthedocs.io.
- **ruff** (formatting and linting) and **uv** (environments and packages): docs.astral.sh.
- **pandas:** pandas.pydata.org.
- **matplotlib:** matplotlib.org.
- **FastAPI:** fastapi.tiangolo.com.
- **httpx:** python-httpx.org.
- **SQLite:** sqlite.org. The SQL language understood by the `sqlite3` module.
- **Visual Studio Code:** code.visualstudio.com, with its Python extension.

## The Book's Code

All the programs, data files, exercise solutions and tests from this book are in its code folder, arranged by chapter, together with `requirements.txt`, which lists the package versions used for testing. Each listing was checked on Python 3.12, 3.13, 3.14 and 3.15. If a newer version of Python or of a package changes an output, the change is usually small, such as a reworded error message; the ideas stay the same.
