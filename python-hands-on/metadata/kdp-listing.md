## Description

Paste the following into the description box. KDP supports basic HTML such as `<b>`, `<i>`, `<ul>`, and `<li>`.

```html
<b>Learn Python by writing it, with every example tested.</b>

<p>This book takes you from your first line of code to tested, packaged programs, one small, clear step at a time. No programming experience is needed.</p>

<p><b>Every example works.</b> Every program in this book is a real file that was run on Python 3.12, 3.13, 3.14 and 3.15 before publication, and the output printed beneath it is the output it produced. Type what you see, and you'll get what you see. Even the error messages are real, and you'll learn to read them.</p>

<p><b>You learn by doing.</b> Each chapter introduces a few ideas in short programs, asks you to try them, and ends with exercises. Every exercise has a worked solution in the back of the book, and every solution is tested too.</p>

<p><b>One project grows with you.</b> Pocket Library, a program for your books, starts as a simple list and grows into a tested command-line app with a SQLite database and a web API, so you see how real programs evolve.</p>

<p><b>Inside, you will learn:</b></p>
<ul>
<li>Variables, numbers, strings, input and output, decisions and loops</li>
<li>Lists, tuples, dictionaries, sets, functions and working with text</li>
<li>Files, CSV and JSON, exceptions, modules and the standard library</li>
<li>Classes, inheritance, dataclasses, comprehensions and generators</li>
<li>Testing with pytest, debugging, logging, virtual environments and packaging</li>
<li>Decorators, context managers, type hints with mypy, pattern matching</li>
<li>Concurrency with threads, processes and asyncio, and how to make code fast</li>
</ul>

<p><b>Then you put it all to work in four projects:</b> a command-line app with SQLite, a data analysis with pandas and charts, a web API with FastAPI, and scripts that automate everyday tasks such as renaming files, finding duplicates, making backups and sending reports.</p>

<p><b>All the code is free to download</b> from the book's GitHub repository, arranged by chapter, with every program checked automatically on Python 3.12 to 3.15.</p>

<p>Written by an automation professional with more than 15 years of experience building in-house tools, many of them in Python.</p>

<p><i>This book is independent and is not affiliated with, sponsored by, or endorsed by the Python Software Foundation. Python is a trademark of the Python Software Foundation.</i></p>
```
