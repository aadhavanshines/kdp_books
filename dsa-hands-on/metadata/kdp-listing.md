## Description

Paste the following into the description box. KDP supports basic HTML such as `<b>`, `<i>`, `<ul>`, and `<li>`.

```html
<b>Don't just read about data structures. Build them, test them and time them.</b>

<p>This book teaches data structures and algorithms in Python the hands-on way. Every structure is a working class you write yourself, a few dozen lines long. Every one is tested against Python's own built-ins on thousands of random inputs. And every one is timed with real benchmarks, so you watch Big O happen on your own screen instead of taking it on faith.</p>

<p><b>Every example works.</b> Every program in this book is a real file that was run on Python 3.12, 3.13, 3.14 and 3.15 before publication, and the output printed beneath it is the output it produced.</p>

<p><b>You will build:</b></p>
<ul>
<li>A dynamic array, singly and doubly linked lists, stacks, queues and a ring buffer</li>
<li>Two kinds of hash table, and see why Python's dict is fast, and when it isn't</li>
<li>A binary heap, binary search trees, a self-balancing AVL tree, a trie and union-find</li>
<li>Graphs, with BFS, DFS, topological sort, Dijkstra, Bellman-Ford, Kruskal and Prim</li>
<li>Eight sorting algorithms, timed against Python's own sort</li>
<li>An LRU cache, the classic interview design question, timed against the standard library</li>
</ul>

<p><b>Then master the interview patterns:</b> two pointers, sliding window, hash maps and prefix sums, BFS and DFS on grids and implicit graphs, dynamic programming, greedy algorithms and backtracking. Each pattern solution is stress tested against a brute force and timed against it, and a chapter on solving problems under pressure ties them together.</p>

<p><b>Real numbers, real software.</b> Every chapter shows where its structure works in the real world, in Python itself, Linux, Git, databases and the internet's routers, with sources listed in the back. A chapter runs the book's benchmarks on four Python versions to measure how much faster Python has become, and a cheat sheet collects every cost with the book's measured times.</p>

<p>Every chapter ends with exercises, and every exercise has a tested, worked solution. If you know basic Python, you're ready.</p>

<p><b>All the code is free to download</b> from the book's GitHub repository, arranged by chapter, with tests, benchmarks and the expected output of every program.</p>

<p><i>This book is independent and is not affiliated with, sponsored by, or endorsed by the Python Software Foundation or any other company or project named in it. Python is a trademark of the Python Software Foundation.</i></p>
```
