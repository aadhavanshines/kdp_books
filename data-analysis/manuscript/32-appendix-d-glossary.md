# Appendix D: Glossary

**A/B test.** An experiment that randomly shows visitors one of two versions and compares the results (Chapters 17 and 23).

**Aggregation.** Combining many values into one, such as a sum, mean or count (Chapter 9).

**Array.** NumPy's table of numbers of one type, operated on all at once (Chapter 3).

**Association.** Two measures moving together; it doesn't by itself show that one causes the other (Chapter 25).

**Bootstrap.** Estimating uncertainty by resampling the data with replacement many times (Chapter 17).

**Broadcasting.** NumPy stretching a smaller array to match a larger one in arithmetic (Chapter 3).

**Categorical type.** A column type storing each distinct value once, with small codes per row (Chapters 5 and 27).

**Confounder.** A third factor that affects both things being compared, such as season (Chapter 25).

**Correlation (r).** A measure from -1 to +1 of how closely two measures move together in a straight line (Chapter 16).

**CSV.** Comma-separated values: a plain-text table format (Chapter 2).

**DataFrame.** pandas' table: columns of data sharing one index (Chapter 4).

**Drawdown.** The fall from the highest value so far (Chapter 24).

**dtype.** The data type of a column, such as `int64`, `float64`, `str` or `datetime64` (Chapter 4).

**Index.** The row labels of a Series or DataFrame (Chapter 4).

**Interquartile range (IQR).** The range of the middle half of the values, from the 25th to the 75th percentile (Chapter 16).

**Join (merge).** Combining two tables by matching key columns (Chapter 10).

**Long and wide tables.** One row per observation versus one column per period or category (Chapter 11).

**Mask.** An array or Series of True/False values used to select items (Chapters 3 and 6).

**Median.** The middle value when values are sorted (Chapter 16).

**Net Promoter Score (NPS).** Percentage of promoters (9 or 10) minus percentage of detractors (0 to 6) (Chapter 22).

**Percentile.** The value below which a given share of values falls; the 95th percentile has 95% below it (Chapter 3).

**Permutation test.** Estimating a p-value by shuffling group labels many times (Chapter 17).

**Pivot table.** A table that groups by one column along the rows and another along the columns (Chapter 9).

**p-value.** How often a difference at least as large would appear by chance alone if there were no real effect (Chapter 17).

**Resampling (time series).** Regrouping data into new time periods, such as days into months (Chapter 12).

**Rolling average.** The average of each value and a fixed number of values before it (Chapter 12).

**Sample ratio mismatch.** An experiment's groups differing in size more than chance allows, a sign of broken assignment (Chapter 23).

**Seed.** A starting number that makes "random" numbers repeatable (Chapter 2).

**Series.** pandas' labeled column of data (Chapter 4).

**Simpson's paradox.** A comparison that reverses when data is split into groups (Chapter 16).

**Skew.** Lopsidedness of a distribution; a long right tail means positive skew (Chapter 16).

**SQL.** The language of relational databases (Chapter 18).

**Standard deviation.** How far values typically are from their mean (Chapter 16).

**Stopwords.** Very common words such as "to" and "the", removed before counting words (Chapter 13).

**Tidy data.** One variable per column, one observation per row, one value per cell (Chapter 11).

**Vectorized operation.** An operation on a whole array or column at once, without a Python loop (Chapters 3 and 8).

**Volatility.** The standard deviation of returns, often annualized (Chapter 24).

**Window function.** A SQL calculation across related rows that keeps every row, such as `RANK() OVER (...)` (Chapter 18).
