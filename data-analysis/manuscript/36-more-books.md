# More Books by the Author

If you enjoyed this book, you may like these, also by Aadhavan Muthurengan and available on Amazon.

**Python Programming Hands-On: Learn Python from Basic to Advanced by Writing Real Programs, with Exercises, Solutions and Every Example Tested.** The natural companion to this book: Python from your first line of code to tested, packaged programs, a database app, a web API and automation scripts, with every example run before publication.

**Python Data Structures and Algorithms: A Comprehensive Guide.** A guide to the data structures and algorithms behind efficient Python programs.

**Vibe Coding for Beginners: Build Real Apps with Claude Code, from Your First Prompt to Tested, Deployed Software.** How to build real web and mobile apps by working with an AI coding assistant, from the first prompt to tested, deployed software.

**Building AI Agents with Claude: A Beginner's Guide to Agents That Use Tools, Remember, and Get Real Work Done, from Your First Agent to Production.** Build AI agents that use tools, remember context and complete real tasks, from a first agent to production.

**Prompt Engineering Mastery: The Complete Beginner-to-Advanced Guide to Getting Better Results from AI Chatbots, Coding Assistants, Image Generators, and Agents.** Practical techniques for getting reliable, high-quality results from AI tools, from everyday chat to coding assistants and agents.
