# Introduction

Every organization runs on data now: sales, sign-ups, survey answers, sensor readings, bank transactions. Most of it sits in spreadsheets and databases, and most of it is never looked at carefully. The people who can turn a messy file into a clear answer, and then explain that answer honestly, are some of the most useful people in any team.

This book teaches you to be one of them, with Python. You'll load real-looking data, clean it, reshape it, summarize it, chart it, test whether a difference is real, and write the result up so that someone else can trust it. By the end you'll have worked through six complete projects, from a year of shop sales to an A/B test, a stock study, a public-health question and a household budget.

## What Makes This Book Different

**Every example is real, tested code.** Each listing in this book is a file that was run on Python 3.12, 3.13, 3.14 and 3.15, with the exact versions of pandas, NumPy and matplotlib listed in Chapter 2, and the output printed beneath it is the output it produced. If you type what you see, you'll get what you see. Every chart was drawn by the code printed next to it.

**One coherent set of data.** Instead of a new toy table on every page, you'll work with the records of one fictional business, Larkspur Home, an online homeware shop: its orders, customers and products, plus a survey, a website experiment, stock prices, city air-quality readings and a household's bank statement. You'll get to know the data, which is how analysis works in real life. Everything is generated by one program with a fixed random seed, printed in full in Appendix F, so every reader has exactly the same data.

**The whole workflow, not just the library.** pandas is the center of the book, but analysis is more than pandas: asking a sharp question, cleaning without fooling yourself, choosing an honest chart, knowing when a difference could be luck, writing SQL, testing your calculations and reporting the result. Each gets its own chapter.

**Real stories, checked.** **Real-World Story** and **Interesting Fact** boxes connect the techniques to things that actually happened: a famous economics paper with a spreadsheet error, thousands of COVID-19 cases lost to a file-size limit, genes renamed because spreadsheets kept turning them into dates. Each comes from a published source, listed in Appendix E.

**Exercises with tested solutions.** Most chapters end with exercises. Appendix A has a worked, tested solution for each.

## Who This Book Is For

You should know basic Python: variables, lists, dictionaries, loops, functions and how to run a program. If you don't yet, *Python Programming Hands-On* teaches exactly that, and its style matches this book. You don't need any statistics or math beyond school arithmetic; the book explains every idea it uses, in plain words, with code you can run.

The book suits students, job-seekers preparing for analyst roles, spreadsheet users who've hit Excel's limits, and engineers, scientists and managers who want to answer their own questions from data.

## How the Book Is Organized

- **Part I, Getting Started:** what analysis is, setting up, and the NumPy basics that pandas is built on.
- **Part II, Working With Tables:** the core of pandas: loading, selecting, cleaning, transforming, grouping, combining and reshaping data, plus dates and text.
- **Part III, Seeing and Explaining:** charts, honest chart design, descriptive statistics, comparing groups and A/B tests, SQL, reports and tests, and using AI assistants safely.
- **Part IV, Six Projects:** complete analyses from question to conclusion.
- **Part V, Going Further:** bigger data, faster code, and where to go next.
- **Appendices:** exercise solutions, a pandas cheat sheet, common errors and fixes, a glossary, sources for the real-world stories, and the program that makes the book's data.

## How to Use the Code

Type the listings yourself if you can; you'll learn more than by reading. Each chapter's programs live in their own folder, next to a shared `data` folder, exactly as Chapter 2 sets up. Change things and rerun: filter a different region, group by another column, try another chart. When something breaks, Appendix C lists the errors analysts meet most often and how to fix them.

> **Note:** All companies, people, products, cities and figures in the datasets are fictional. Real companies and events appear only in the clearly marked real-world boxes, as published by their sources.
