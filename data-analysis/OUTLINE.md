# Data Analysis with Python, Hands-On: Outline

Audience: people who know basic Python (or have read *Python Programming Hands-On*) and want to analyze real data: students, job-seekers, spreadsheet users, engineers and analysts. Every listing is a real file in `code/`, run on Python 3.12 to 3.15 with pinned packages, and its output is printed beneath it. All data is fictional and generated by a printed, seeded script.
