## Description

Paste the following into the description box. KDP supports basic HTML such as `<b>`, `<i>`, `<ul>`, and `<li>`.

```html
<b>Turn raw data into answers you can trust, with every example tested.</b>

<p>This book teaches data analysis with Python and pandas, one small, clear step at a time: from your first table to complete, repeatable reports. If you know basic Python, you're ready.</p>

<p><b>Every example works.</b> Every program in this book is a real file that was run on Python 3.12, 3.13, 3.14 and 3.15 before publication, and the output printed beneath it is the output it produced. Every chart was drawn by the code printed next to it.</p>

<p><b>The same numbers on your computer.</b> All the datasets (an online shop's orders and customers, a survey, an A/B test, stock prices, air quality and clinic visits, and a household budget) are made by one short program printed in the book, with a fixed random seed. Run it, and you get exactly the numbers in the book.</p>

<p><b>Inside, you will learn to:</b></p>
<ul>
<li>Work in plain Python files or Jupyter notebooks</li>
<li>Load CSV files, spreadsheets, JSON and databases, and save your results</li>
<li>Find and clean messy data: missing values, duplicates, inconsistent text and the date trap that swaps days and months</li>
<li>Select, filter, transform, group, join and reshape tables</li>
<li>Work with dates, time series, rolling averages and text patterns</li>
<li>Draw clear, honest charts, and spot misleading ones</li>
<li>Describe data with statistics, find delayed correlations and recognize Simpson's paradox</li>
<li>Test whether a difference is real with the bootstrap and the permutation test</li>
<li>Write SQL for analysis, including joins and window functions</li>
<li>Test your analysis code, automate reports, and check AI-generated analysis safely</li>
<li>Handle bigger data with smaller types, chunks and readable pipelines</li>
</ul>

<p><b>Then you put it all together in six projects:</b> a retail sales review, a customer survey, a website A/B test, a stock price study, air quality and clinic visits, and a household budget.</p>

<p><b>Real stories, checked.</b> Short boxes tell what happened when data went wrong in the real world, from a spreadsheet error in a famous economics paper to thousands of COVID-19 cases lost to a file-size limit, with sources listed in the back.</p>

<p>Every chapter ends with exercises, and every exercise has a tested, worked solution.</p>

<p><b>All the code and data are free to download</b> from the book's GitHub repository, arranged by chapter, with the expected output of every program, a ready-to-run Jupyter notebook for every chapter, and an automatic check that runs everything on Python 3.12 to 3.15. Chapter 2 shows how to work in Jupyter notebooks, step by step.</p>

<p>Written by an automation professional with more than 15 years of experience turning engineering data into reliable tools and reports.</p>

<p><i>This book is independent and is not affiliated with, sponsored by, or endorsed by the Python Software Foundation or any other company or project named in it. Python is a trademark of the Python Software Foundation.</i></p>
```
