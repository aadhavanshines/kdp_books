# Appendix A: Timeline of Language AI

Key moments in the story told in this book. Chapters where each is explained are given in brackets.

| Year | Event |
| --- | --- |
| 1943 | Warren McCulloch and Walter Pitts describe a mathematical model of a neuron [6] |
| 1950 | Alan Turing proposes the "imitation game" in "Computing Machinery and Intelligence" [2] |
| 1951 | Claude Shannon measures how predictable English is with a letter-guessing game [1] |
| 1956 | The Dartmouth workshop gives "artificial intelligence" its name [2] |
| 1958 | Frank Rosenblatt builds the perceptron, a machine that learns [6] |
| 1966 | Joseph Weizenbaum's ELIZA chatbot at MIT [2] |
| 1986 | Rumelhart, Hinton and Williams popularize backpropagation [6] |
| 1993 | NVIDIA is founded [9] |
| 2003 | Yoshua Bengio and colleagues publish a neural language model [2] |
| 2006 | NVIDIA releases CUDA, opening GPUs to general computing [9] |
| 2008 | Common Crawl begins archiving the web [5] |
| 2012 | AlexNet, trained on two gaming GPUs, wins ImageNet [2, 9] |
| 2013 | word2vec: king − man + woman ≈ queen [4] |
| 2014 | Sequence-to-sequence learning; attention for translation; GANs; the Adam optimizer [2, 6, 25] |
| 2015 | OpenAI founded; knowledge distillation; first diffusion-model paper; Google begins using TPUs [9, 18, 23, 25] |
| 2016 | AlphaGo beats Lee Sedol; WaveNet speaks [23, 26] |
| 2017 | "Attention Is All You Need" introduces the Transformer; RLHF from human preferences; mixture-of-experts layer [7, 13] |
| 2018 | GPT-1 and BERT [2] |
| 2019 | GPT-2 and its staged release; "The Bitter Lesson" [2, 8] |
| 2020 | Scaling laws; GPT-3 (175B parameters); retrieval-augmented generation; Vision Transformer; denoising diffusion; The Pile; MMLU [8, 15, 19, 24, 25] |
| 2021 | CLIP; DALL·E; LoRA; Anthropic founded; "Stochastic Parrots" [18, 23, 24, 25, 27] |
| 2022 | Chinchilla; InstructGPT; chain-of-thought; FlashAttention; Constitutional AI; BLOOM; Stable Diffusion, Midjourney and DALL·E 2; Whisper; ChatGPT (30 November) [8, 13, 14, 25, 26] |
| 2023 | GPT-4; LLaMA and its leak; Claude; Bard; Mistral 7B and Mixtral; DPO; vLLM; QLoRA; llama.cpp; Mamba; Gemini 1.0; SWE-bench; first AI Safety Summit [7, 13, 16, 17, 18, 21, 22, 23] |
| 2024 | Sora preview; Gemini 1.5 with million-token context; Llama 3 and 3.1 405B; GPT-4o; Claude 3 and 3.5; FineWeb; o1 reasoning model (12 September); Nobel Prizes for Hinton, Hopfield, Hassabis and Jumper; Anthropic's computer use and MCP; DeepSeek-V3; EU AI Act in force [6, 11, 12, 14, 19, 20, 22] |
| 2025 | DeepSeek-R1 and NVIDIA's record one-day fall; Stargate announced; Claude 3.7 Sonnet hybrid reasoning; Llama 4; Qwen3; Veo 3 with sound; Kimi K2; gpt-oss; GPT-5; IMO gold-medal performance; Sora 2; Gemini 3; Olmo 3; MCP donated to the Agentic AI Foundation [10, 12, 14, 20, 22, 23, 26] |
| 2026 | Claude's new constitution; GLM-5; Gemma 4 under Apache 2.0; Sora discontinued; DeepSeek-V4 preview; Meta's Muse family; GPT-6 family; Gemini 4 Argon; Claude 5.5 family; Muse Wonder; Muse Spark Open [13, 22, 23, 26] |
