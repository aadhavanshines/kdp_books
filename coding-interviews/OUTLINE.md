# The Coding Interview Playbook: outline

Working title: The Coding Interview Playbook
Subtitle: 120 Original Problems with Tested Python Solutions, Patterns, System Design and Mock Interviews to Prepare for Top Tech Company Interviews

Every problem is original (own wording, stories and data) and has: statement, examples, constraints, hints, brute force, optimal solution(s), complexity, common mistakes, follow-ups. Every solution is a real file in code/, checked on Python 3.12-3.15 against examples and against a brute-force solution on random inputs.
