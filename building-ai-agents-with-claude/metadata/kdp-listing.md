<b>Chatbots answer. Agents get the work done.</b>

<p>An AI agent reads, decides, uses tools and checks its own results. It can sort your inbox, turn receipt photos into a checked spreadsheet, answer customers, analyse a year of sales, and brief you every morning. It can also refund the wrong order, obey an email written by a scammer, or report "success" with empty answers. <i>Building AI Agents with Claude</i> teaches you to build agents that are useful, safe and reliable, and to prove it.</p>

<p><b>Everything in this book is real.</b> You will build nine agents for one small business, a home bakery in Chennai, using Claude and the Claude Agent SDK for Python. Refunds are checked in the database, not in the agent's description of what it did. Every agent was run several times, and every score is in the book.</p>

<li>Research Analyst: answers a business question with verified quotes</li>
<li>Data Analyst: writes and runs its own Python, safely, in a sandbox</li>
<li>Support Desk: a web chat that issues refunds, with guardrails in code and an owner's approval</li>
<li>Kitchen Manager: plans orders through your own MCP server</li>
<li>Launch Team: four specialist agents prepare a Diwali campaign, with a fact-checker</li>
<li>ShopMate: a morning-brief agent taken all the way through planning, testing, Docker, scheduling, monitoring and maintenance</li>

<li>Use permissions, hooks, sandboxes, kill switches and human approval</li>
