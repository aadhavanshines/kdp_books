# Appendix F: Resources

The tools in this book change often. These official sources are kept up to date, and are the best places to check anything that may have changed since October 2026, when these addresses were checked.

## Claude and the Agent SDK

- **Claude developer documentation:** platform.claude.com/docs. Guides and references for the Claude API, models, pricing, tool use, structured outputs and prompt engineering.
- **Agent SDK documentation:** the "Agent SDK" section of the developer documentation, with an overview, guides for permissions, hooks, sessions, MCP, subagents and structured outputs, and full references for Python and TypeScript.
- **Agent SDK for Python on GitHub:** github.com/anthropics/claude-agent-sdk-python. The source code, examples and the changelog. Read the changelog before upgrading.
- **Claude Code documentation:** code.claude.com/docs. Includes network configuration (code.claude.com/docs/en/network-config), settings and MCP.
- **Models and pricing:** platform.claude.com/docs/en/about-claude/models/overview and platform.claude.com/docs/en/about-claude/pricing. Check these before choosing a model or estimating cost.
- **Model deprecations:** the "Model deprecations" page of the developer documentation lists retirement dates.
- **The Claude Console:** platform.claude.com. API keys, usage and costs, spending limits and workspaces.
- **Anthropic's Usage Policy:** anthropic.com/legal/aup. What Claude may and may not be used for.

## MCP

- **Model Context Protocol:** modelcontextprotocol.io. The specification, guides for building servers and clients, and a list of SDKs.
- **MCP Python SDK:** github.com/modelcontextprotocol/python-sdk, which includes `FastMCP`, used in Chapter 13.

## Tools Used in This Book

- **Python:** python.org, and its tutorial at docs.python.org.
- **FastAPI:** fastapi.tiangolo.com, for the web apps in Chapters 12 and 21.
- **pandas** (pandas.pydata.org), **matplotlib** (matplotlib.org) and **openpyxl** (openpyxl.readthedocs.io), for data, charts and Excel.
- **Docker:** docs.docker.com.
- **GitHub Actions:** docs.github.com/actions, including scheduled workflows and encrypted secrets.

## Data Protection

- **India:** the Digital Personal Data Protection Act, 2023, and its rules, published by the Ministry of Electronics and Information Technology (meity.gov.in).
- **European Union:** the General Data Protection Regulation (GDPR).
